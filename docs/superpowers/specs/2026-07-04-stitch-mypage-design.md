# 마이페이지 (Stitch) 디자인 구성

- 프로젝트: App UI Concept Planning (Stitch `projects/12684725898331039692`)
- 디자인 시스템: `Dalbit Suwon` (`assets/1743667ac4f84f3ca1a27cc1974d73bb`)
- 참고 문서: `2026-05-25-dalbit-suwon-mvp-design.md` (Stitch 프로젝트 내 업로드본), 9.5절 "찜/마이"
  - 마이 화면은 최소 범위: 로그인, 위치 권한 상태, 찜 보기, 최근 진행 코스로 제한

## 배경

기존 Stitch 프로젝트에 게스트(비로그인) 상태의 "마이" 화면(`screens/2bcd747892c14fb3a267628d76132426`, "마이 - 달빛수원 (국문)")이 이미 존재한다. 최근 Apple 로그인이 코드에 구현되었으나 로그인 후 상태의 마이페이지 디자인은 없고, 하단 탭바의 "Bookmarks" 탭 목적지 화면도 아직 없다. 이번 작업은 이 세 화면을 Stitch 상에서 구성한다.

## 범위

1. 게스트 마이페이지 리파인 (기존 화면 편집)
2. 로그인 상태 마이페이지 신규 생성
3. 찜(즐겨찾기) 목록 화면 신규 생성 (Bookmarks 탭 목적지)

코드(Flutter) 구현은 이번 범위에 포함하지 않는다. Stitch 화면 디자인 산출물까지가 범위다.

## 1. 게스트 마이페이지 리파인

기존 레이아웃 골격(프로필 카드 → 최근 진행 코스 → 활동 통계 → 설정 리스트 → 하단 탭바) 유지, 아래만 조정:

- 헤더: 알림(bell) 아이콘 제거, "마이" 타이틀만 표시 (비로그인 상태에 알림 기능 무의미)
- 프로필 카드: 기본 실루엣 아바타 대신 달(moon) 모티프 플레이스홀더 아이콘. CTA는 기존 옐로우(Moonlight Gold) 그라디언트 + ambient glow 유지
- 활동 통계 카드: "방문한 장소 / 완료한 코스" 숫자 아래 "로그인 시 기기 간 동기화" 안내 텍스트 추가
- 설정 리스트: 위치 권한 항목에 현재 상태 pill(예: "허용됨"/"미설정") 표시, 아이콘 스타일 통일

## 2. 로그인 상태 마이페이지 (신규)

게스트 화면과 동일한 레이아웃 골격 유지, 변경점:

- 헤더: "마이" 타이틀 + 알림(bell) 아이콘 복원
- 프로필 카드: 실제 프로필 이미지(원형) + 닉네임 + 로그인 provider 배지(예: Apple 아이콘 + "Apple로 로그인함"). 로그인 CTA 제거, "프로필 편집" 텍스트 버튼으로 대체
- 활동 통계 카드: 게스트와 동일 형태, 동기화 안내 문구는 제거
- 설정 리스트: 위치 권한/알림 설정/버전 정보/자주 묻는 질문 유지, 하단에 **로그아웃**, **회원탈퇴**(error 컬러 톤) 메뉴 추가

## 3. 찜 목록 화면 (신규, Bookmarks 탭 목적지)

- 헤더: "찜" 타이틀
- 상단 세그먼트 탭: "코스" / "스팟"
- 리스트: 기존 "스팟 카드"(가로형, Midnight Surface 배경, 16px 라운드) 컴포넌트 재사용, 각 카드에 찜 해제(하트) 아이콘
- 빈 상태: "아직 찜한 스팟이 없어요" + 홈 이동 유도 문구
- 비로그인 사용자: 로컬 저장된 찜 목록은 그대로 노출하되 하단에 "로그인하고 기기 간에도 찜을 동기화하세요" 배너 (MVP 문서의 "찜 클릭 시 로그인 유도" 정책과 일치)
- 하단 탭바: 기존 4탭(Home/Nearby/Bookmarks/My) 유지, Bookmarks 활성화 상태로 표시

## 실행 방식

Stitch MCP 도구로 진행:

- 게스트 마이페이지: `edit_screens`로 기존 화면(`2bcd747892c14fb3a267628d76132426`) 수정
- 로그인 상태 마이페이지: `generate_screen_from_text`로 신규 생성, `designSystem`에 `assets/1743667ac4f84f3ca1a27cc1974d73bb` 지정
- 찜 목록 화면: `generate_screen_from_text`로 신규 생성, 동일 디자인 시스템 지정

각 생성/편집 후 스크린샷을 확인해 디자인 시스템 톤(다크 배경, Moonlight Gold/Soft Amber 포인트, Glassmorphic 카드)과 일치하는지 검증한다.
